LangBar

Исправляет текст, набранный не в той раскладке. Выделите его, зажмите две клавиши рядом с пробелом и отпустите. Работает в Telegram и в остальных программах.

⌥ ⌘

На Mac нужен доступ «Универсальный доступ» для LangBar. Приложение ничего не отправляет в сеть.

Подписанная сборка для установки появится здесь, как только сертификат Developer ID будет готов.
